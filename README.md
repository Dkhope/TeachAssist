# TeachAssist

> **Plan Smarter. Research Faster. Teach Better.**

TeachAssist is an AI-powered teacher productivity platform designed to help educators streamline planning, research, and administrative tasks through a single, intuitive web application.

---

# 📖 Project Overview

Teachers often spend significant time managing schedules, researching educational content, preparing lessons, and handling administrative responsibilities. These tasks can reduce the time available for effective teaching and student engagement.

TeachAssist addresses these challenges by providing a centralized platform that combines AI-powered task planning, research assistance, and an interactive AI assistant. The application helps educators improve productivity, stay organized, and make informed decisions while maintaining a user-friendly experience.

# 🚀 Setup Instructions

## Prerequisites

Ensure the following software is installed:

- Node.js
- npm

Verify installation:

```bash
node --version
npm --version
```

### Clone the Repository

```bash
git clone https://github.com/DkHope/teachassist.git
```

Navigate to the project directory:

```bash
cd teachassist
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

### Open the Application

Open your browser and navigate to:

```text
http://localhost:3000
```

or the development URL displayed in the terminal.

# 📘 Usage

## AI Task Planner

1. Open the **Task Planner** module.
2. Enter tasks, deadlines, and priorities.
3. Generate a daily or weekly schedule.
4. Review the prioritized schedule generated by the AI.

### Example Prompt

```text
Create a weekly schedule for lesson planning, assignment marking, parent meetings, and exam preparation.
```

---

## AI Research Assistant

1. Open the **Research Assistant** module.
2. Enter a topic, article text, or URL.
3. Generate an AI summary.
4. Review the key insights and recommendations.

### Example Prompt

```text
Summarize this article and provide recommendations for teaching Grade 10 Physical Sciences.
```

---

## AI Assistant

1. Open the **AI Assistant** module.
2. Enter a teaching or productivity-related question.
3. Submit your prompt.
4. Review the AI-generated response.

### Example Prompt

```text
Suggest five engaging classroom activities for Grade 8 Mathematics.
```

# 🧠 Responsible AI Notice

TeachAssist is designed to support educators through AI-generated schedules, summaries, recommendations, and conversational assistance.

While AI can increase efficiency and productivity, generated content may not always be accurate, complete, current, or appropriate for every educational context.

Users should:

- Verify information before applying it.
- Review recommendations critically.
- Use professional judgment when making educational decisions.
- Ensure content aligns with curriculum requirements and institutional policies.
- Treat AI outputs as guidance rather than authoritative information.

TeachAssist is intended to support educators, not replace professional expertise and decision-making.
